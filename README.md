# FPL Fantasy Prediction AI Agent

AI-powered Fantasy Premier League prediction system.

## Project Structure

- `config/` - Configuration and settings
- `data/raw/` - Raw data from FPL API
- `src/` - Source code
  - `collectors/` - Data collection modules
  - `data/` - Data validation and processing
  - `utils/` - Utility functions
- `scripts/` - Data fetching and processing scripts
- `logs/` - Application logs
- `tests/` - Test suite

## Requirements

See `requirements.txt` for dependencies.

## Setup

1. Create a `.env` file based on `.env.example`
2. Install dependencies: `pip install -r requirements.txt`
3. Run data collection scripts from `scripts/`

## Development

See config files for environment-specific settings.
